# 海底采集游戏原创复刻方案

## 1. 文档定位

本文档用于把一款“海底采集 + 氧气限制 + 返航出售 + 升级后继续下潜”的 2D 游戏，整理成一份适合 `C++ 图形化课程大作业` 的原创实现方案。

本方案只保留核心玩法循环，不复制任何具体表达，包括但不限于：

- 原游戏名称
- 原游戏角色设定
- 原游戏美术风格与素材
- 原游戏 UI 排版
- 原游戏文案
- 原游戏音效
- 原游戏关卡布局
- 原游戏数值曲线

为了确保原创性，本文档将项目重新定义为一个新的作品原型：

`项目代号：深潮回收站`

玩家扮演一名经营海上回收站的潜航员，驾驶小型潜水器进入深海，收集发光生物、矿物碎片和可回收漂流物，带回海面据点加工出售，再用收益升级潜水器，最终抵达更深海域并解锁完整图鉴。

---

## 2. 设计目标

本项目的设计目标不是“机械复制”，而是做出一个有明显参考来源、但表达方式独立的原创作品。课程大作业更看重以下几点：

- 是否是 `C++` 图形化程序
- 是否有清晰的面向对象设计
- 是否有完整的游戏循环
- 是否有可展示的技术亮点
- 是否有足够的完成度和演示效果

因此，本方案优先满足：

1. 可在较短周期内完成。
2. 画面不依赖高质量美术资源也能运行。
3. 游戏机制清晰，便于视频讲解。
4. 系统设计有层次，便于写实验报告。
5. 可以自然拆分为多个 Git 版本提交。

---

## 3. 原创化改造原则

### 3.1 必须保留的核心体验

- 下潜探索
- 氧气限制
- 采集资源
- 返回基地
- 出售资源
- 升级装备
- 解锁更深区域

### 3.2 必须主动替换的表达层

- 主角不使用原作角色设定，改为“回收站潜航员”
- 采集物不直接照搬某一具体生物分类，改为“发光漂浮体、壳晶、热泉凝胶、深海废料”等原创资源
- 商店不采用原作的店铺表现，改为“海面回收站结算台”
- 地图风格改为“深海断层区、热泉区、冷流峡谷区”
- UI 配色和构图采用自己的方案
- 特殊生物机制重新命名并换皮

### 3.3 不建议直接照搬的内容与替换方案

#### 不建议直接照搬 1：某种具体海洋生物作为唯一核心商品

替换方案：

- 使用多类资源体系
- 例如：`荧团浮体`、`壳晶矿`、`冷凝胶`、`旧时代金属件`
- 这样更利于设计采集差异和升级材料差异

#### 不建议直接照搬 2：完全相同的推进节奏

替换方案：

- 使用“深度许可证”机制
- 玩家达到指定收益和图鉴收集率后，获得进入下一层海域的许可

#### 不建议直接照搬 3：完全相同的升级项

替换方案：

- 基础升级仍保留，但名称和效果组合改写
- 例如把“氧气升级”改为“压缩气瓶等级”
- 把“抓取升级”改为“回收机械臂效率”

#### 不建议直接照搬 4：完全相同的敌对单位

替换方案：

- 设计 3 类原创干扰体
- 例如：电弧鳐、裂壳螺、脉冲水母群

## 4. 核心玩法循环

整个游戏的闭环如下：

1. 玩家在海面基地选择出航。
2. 驾驶潜水器进入海域并持续下潜。
3. 在氧气耗尽前搜索并采集资源。
4. 遇到风险时决定继续探索还是返航。
5. 成功返回海面后结算收益。
6. 将资源出售换成货币，部分资源保留用于升级。
7. 在基地升级潜水器与工具。
8. 解锁更深海域与更高价值资源。
9. 重复循环，直到达成最终目标。

这个循环的核心乐趣来自三件事：

- `风险控制`：氧气有限，越深风险越大
- `收益判断`：继续探索可能赚更多，也可能无法返航
- `成长反馈`：每次返航都能明显感受到下次更强

## 5. 游戏总目标与胜负条件

## 5.1 总目标

玩家最终目标可以设计为以下任意一种，建议同时使用：

- 抵达最终深度，例如 `1200m`
- 解锁全部海域
- 完成资源图鉴 `80% 以上`
- 建成满级海上回收站

### 5.2 单次出航的失败条件

- 氧气耗尽且未返回安全区
- 生命值归零
- 潜水器结构耐久清零

### 5.3 单次出航的成功条件

- 主动返回海面并完成结算
- 到达本次指定任务深度后撤离

### 5.4 整局游戏的阶段性胜利条件

- 第一次到达 `100m`
- 第一次带回稀有资源
- 第一次解锁热泉区
- 第一次制造高级推进器

## 6. 世界观与资源体系

为了让项目原创且更容易写报告，建议加入轻量世界观：

数十年前近海发生了一次海底设施坍塌，留下大量可回收结构件与异常生态群。玩家所在的海面回收站负责回收深海遗留物，并记录异常生物样本。

### 6.1 资源分类

建议至少设计四类资源：

1. `荧团浮体`
   - 作用：主要售卖资源
   - 特点：数量多、价值低、分布浅

2. `壳晶矿`
   - 作用：升级材料
   - 特点：附着在岩壁，需要短暂停留采集

3. `冷凝胶`
   - 作用：氧气装备和耐压部件升级材料
   - 特点：中层海域产出

4. `旧时代零件`
   - 作用：高阶模块制作材料
   - 特点：稀有、风险高、深海区域产出

### 6.2 资源稀有度

每类资源可以设置普通、稀有、珍贵三档，用颜色区分：

- 普通：白色或浅蓝
- 稀有：绿色或金色
- 珍贵：红色或紫红

### 6.3 收益结构

建议不要把所有资源都直接卖钱，而是分成：

- `可出售资源`
- `可出售也可保留的稀有资源`
- `只能用于升级的材料资源`

这样会逼迫玩家做资源决策，而不是无脑卖出全部资源。

## 7. 核心系统拆分

## 7.1 基础移动系统

### 功能目标

玩家可以在 2D 水下世界中自由移动，体验“下潜”和“返航”的空间压力。

### 推荐表现方式

- 侧视 2D 地图
- 玩家以潜水器或小型潜航服形象出现
- 方向控制：`WASD` 或方向键

### 移动规则

- `A / D`：左右移动
- `W`：上浮
- `S`：下潜
- 长按方向键时持续移动
- 移动速度受装备和海域阻力影响

### 建议实现细节

- 使用 `float x, y` 表示位置
- 使用 `vx, vy` 表示速度
- 每帧更新坐标
- 地图边界做碰撞限制
- 岩壁与障碍物使用 AABB 碰撞盒

### 可选扩展

- 水流区域会改变速度方向
- 深层区域移动阻力更大
- 携带过多货物后机动性下降

### 验证方法

- 玩家在空地图中可以平滑上下左右移动
- 角色不能穿出地图边界
- 角色撞到障碍会停止或滑开

---

## 7.2 氧气系统

### 功能目标

氧气系统是最核心的风险控制机制，决定玩家每次出航的最大行动时间。

### 基础规则

- 玩家出航时拥有最大氧气值
- 氧气随时间持续下降
- 下潜越深，氧气下降速度可略微增加
- 特殊状态如冲刺、受伤、采矿可额外消耗氧气

### 推荐公式

```text
当前氧气 = 当前氧气 - 基础消耗 - 深度附加消耗 - 行为附加消耗
```

示例：

```text
基础消耗：每秒 1
深度附加：每 100m 额外 +0.15 / 秒
冲刺附加：每秒 +0.5
采矿附加：每秒 +0.3
```

### 安全设计

- 当氧气低于 25% 时，UI 变黄
- 当氧气低于 10% 时，UI 变红并闪烁
- 氧气为 0 时开始扣生命值

### 原创增强方案

加入“备用气囊”机制：

- 玩家可以携带一次性补氧包
- 使用后恢复固定氧气
- 不可无限购买，需占背包格子

### 验证方法

- 静止不动时氧气仍持续下降
- 深度变深后下降速度变快
- 使用补氧包可恢复氧气
- 氧气耗尽后触发危险状态

---

## 7.3 采集系统

### 功能目标

通过不同采集对象和不同采集方式，构建探索乐趣。

### 采集对象类型

1. 漂浮资源
   - 靠近后按键拾取
   - 适合浅层新手期

2. 附着资源
   - 靠近岩壁后持续采集 1 至 2 秒
   - 中期主要升级材料来源

3. 危险资源
   - 靠近后会触发小范围伤害或惊动敌对生物
   - 高收益高风险

4. 遗迹容器
   - 需要钥匙或炸裂工具解锁
   - 提供稀有零件

### 交互方式

- 接近资源后显示交互提示
- 按 `J` 或空格键开始采集
- 采集过程可以显示进度条
- 采集中移动会中断

### 背包设计

建议采用“重量 + 格子”混合设计中的简化版：

- 基础做法：只做 `背包容量上限`
- 进阶做法：资源有不同体积，占不同格数

课程大作业建议优先使用基础做法：

- 最大容量 20
- 每种资源占 1 到 3 格

### 验证方法

- 角色接近资源时出现提示
- 采集后资源从地图移除并加入背包
- 背包满时不能继续拾取
- 中断采集时不应错误增加资源

---

## 7.4 出售系统

### 功能目标

让每次出航的成果回到基地后形成明确的结算反馈。

### 结算流程

1. 返回海面基地
2. 系统弹出本次收获面板
3. 显示资源数量、单价、总收入
4. 玩家选择出售哪些资源
5. 获得货币
6. 进入升级或再次出航

### 建议规则

- 普通资源默认建议全部出售
- 稀有资源可以“卖钱”或“保留升级”
- 升级材料默认不出现在出售列表中，防止误操作

### 市场波动机制

为了增强趣味，可以加入轻量市场浮动，但不要过于复杂：

- 每次返航后，普通资源价格在 `±10%` 内波动
- 稀有资源价格变化更大

如果时间紧，市场波动可以暂时不做。

### 验证方法

- 结算界面能显示本次采集内容
- 出售后玩家金币增加
- 未出售资源应正确保留
- 连续多次返航不会出现重复结算

---

## 7.5 升级系统

### 功能目标

升级系统负责提供长期成长反馈，是驱动玩家反复下潜的主要动力。

### 升级分类

建议至少做 6 类：

1. `压缩气瓶`
   - 提高最大氧气值

2. `推进器`
   - 提高移动速度

3. `机械臂`
   - 提高采集速度

4. `货舱扩容`
   - 提高背包容量

5. `耐压外壳`
   - 降低深层区域伤害或减缓结构损耗

6. `扫描模块`
   - 提高资源显示范围

### 升级结构建议

采用“固定等级升级”最适合课程项目：

- 每项最多 5 级
- 每级都有明确效果
- 升级成本逐步提高

示例：

| 升级项 | 1级效果 | 满级效果 |
|---|---|---|
| 压缩气瓶 | 氧气 +20 | 氧气 +120 |
| 推进器 | 速度 +5% | 速度 +30% |
| 机械臂 | 采集时间 -10% | 采集时间 -40% |
| 货舱扩容 | 容量 +4 | 容量 +20 |

### 原创增强方案

加入“模块槽位”：

- 玩家可装备 2 个被动模块
- 例如“低耗呼吸阀”“抗电外壳”“双倍扫描”

如果时间不足，这部分可以作为拓展功能写进报告，不一定实现。

### 验证方法

- 升级前后数值变化可见
- 升级消耗货币或材料
- 等级达到上限后无法继续升级

---

## 7.6 关卡推进系统

### 功能目标

将地图从单一区域扩展为多层海域，形成持续的新鲜感。

### 推荐海域划分

1. `浅滩回收区`
   - 深度：0m - 150m
   - 特点：安全，新手教学区

2. `断层矿脉区`
   - 深度：150m - 400m
   - 特点：矿物多，障碍增多

3. `热泉裂谷区`
   - 深度：400m - 750m
   - 特点：热流喷口，持续伤害地形

4. `冷流暗海区`
   - 深度：750m - 1200m
   - 特点：能见度低，危险生物强

### 解锁条件建议

- 到达指定深度
- 赚到指定总收益
- 收集指定数量的关键材料

示例：

- 解锁第二海域：累计收益达到 1500
- 解锁第三海域：获得 10 个壳晶矿和 5 个冷凝胶
- 解锁第四海域：达到 600m 且完成推进器三级升级

### 地图生成方案

课程项目建议优先采用 `手工地图`，不要一开始做程序生成。

原因：

- 手工地图更稳定
- 更容易调试
- 更利于视频展示

后期如果有时间，可加入简易随机刷资源机制：

- 地图地形固定
- 资源刷新位置半随机

### 验证方法

- 达成条件前无法进入新海域
- 达成条件后正确解锁
- 不同海域资源和危险分布有差异

---

## 7.7 敌对与特殊生物系统

### 功能目标

让海域不仅是采集场，也存在移动风险和决策压力。

### 建议设计 3 种特殊单位

#### 1. 电弧鳐

- 行为：缓慢巡逻
- 效果：接触后使玩家短暂失控或扣氧气
- 设计意义：让玩家避免直线乱冲

#### 2. 裂壳螺

- 行为：附着在墙体，玩家靠近时突然弹射
- 效果：造成耐久伤害
- 设计意义：约束贴墙采矿的节奏

#### 3. 脉冲浮群

- 行为：成群漂浮，定时放出脉冲
- 效果：短暂关闭扫描器或照明
- 设计意义：制造深层压迫感

### 特殊生态现象

- 热泉喷口：定时喷发，造成伤害
- 强水流通道：推动玩家偏离路线
- 黑暗区域：缩小可视范围

### 验证方法

- 特殊单位具备独立行为
- 玩家接触后会触发明确效果
- 效果结束后系统能恢复正常

## 8. 数值设计方案

下面给出一套适合大作业原型的初始数值，可直接作为第一版使用。

## 8.1 玩家基础数值

| 数值项 | 初始值 | 说明 |
|---|---:|---|
| 最大氧气 | 100 | 每次出航初值 |
| 最大生命 | 3 | 可简化为 3 格 |
| 移动速度 | 180 | 像素/秒 |
| 背包容量 | 12 | 格数 |
| 基础采集时间 | 1.2 秒 | 普通资源 |
| 初始金币 | 0 | 初始不送太多钱 |

## 8.2 资源价值示例

| 资源 | 单价 | 常见区域 | 用途 |
|---|---:|---|---|
| 荧团浮体 | 15 | 浅层 | 售卖 |
| 壳晶矿 | 35 | 中层 | 升级为主 |
| 冷凝胶 | 60 | 中深层 | 升级为主 |
| 旧时代零件 | 120 | 深层 | 高级升级 |
| 稀有核片 | 200 | 极深层 | 终局材料 |

## 8.3 升级价格示例

| 升级项 | 1级 | 2级 | 3级 | 4级 | 5级 |
|---|---:|---:|---:|---:|---:|
| 压缩气瓶 | 100 | 180 | 300 | 450 | 650 |
| 推进器 | 120 | 220 | 360 | 520 | 700 |
| 机械臂 | 100 | 180 | 280 | 420 | 600 |
| 货舱扩容 | 80 | 160 | 260 | 380 | 520 |
| 耐压外壳 | 150 | 260 | 400 | 580 | 800 |

### 数值设计原则

- 第一小时内要能明显感受到升级收益
- 前两次返航就应能买到一项升级
- 不要把升级价格定得太高，否则演示效果差

## 9. UI 界面设计方案

## 9.1 界面总览

建议设计 5 个主要界面：

1. 开始菜单
2. 基地界面
3. 出航游戏界面
4. 结算界面
5. 升级界面

## 9.2 开始菜单

包含：

- 开始游戏
- 继续游戏
- 操作说明
- 退出

视觉建议：

- 背景为夜晚海面与远处灯塔
- 标题使用自己的项目名，例如 `深潮回收站`

## 9.3 基地界面

包含：

- 当前金币
- 当前升级状态
- 海域选择
- 出航按钮
- 升级入口

## 10. 技术实现方案

## 10.1 推荐技术栈

首选：

- `C++`
- `Qt Widgets`
- `QPainter`
- `QTimer`
- `QPixmap`

推荐原因：

- 课程作业中较常见
- 有成熟 GUI 支持
- 资源加载、窗口切换、键盘输入都较方便
- 适合 2D 原型开发

如果你完全不会 Qt，也可以用：

- `EasyX + C++`

但若从可维护性和报告描述角度看，Qt 更好。

## 10.2 程序结构建议

## 10.4 主循环设计

使用 `QTimer` 驱动固定帧更新，例如 16ms 一次：

```text
定时器触发
-> 读取输入状态
-> 更新玩家位置
-> 更新敌人行为
-> 结算碰撞
-> 扣除氧气
-> 检查采集与拾取
-> 检查返航或失败
-> 调用 repaint()
```

## 12. 详细开发步骤与验证方法

下面按照“先做什么、再做什么、怎么验证”的要求给出可执行步骤。

## 阶段 0：建工程与准备资源

### 要做什么

1. 新建 Qt Widgets 项目
2. 创建基本目录结构
3. 准备占位图片资源
4. 先用简单色块代替正式美术

### 输出结果

- 程序可以启动
- 出现一个主窗口
- 能显示背景

### 怎么验证

- 点击运行后无崩溃
- 主窗口大小正常
- 资源文件能正确加载

---

## 阶段 1：先做主场景与玩家移动

### 要做什么

1. 创建 `GameScene`
2. 创建 `Player` 类
3. 处理键盘输入
4. 实现上下左右移动
5. 在场景中绘制玩家

### 输出结果

- 玩家可以在场景中移动

### 怎么验证

- 按方向键后角色立即响应
- 松开按键后停止移动
- 连续运行 1 分钟不出现明显卡顿

---

## 阶段 2：加入地图边界与障碍碰撞

### 要做什么

1. 定义地图尺寸
2. 加入岩石或墙体障碍
3. 做矩形碰撞检测

### 输出结果

- 玩家不能穿墙
- 玩家被限制在地图范围内

### 怎么验证

- 贴着障碍移动时不会穿过去
- 冲向地图边缘时会停下

---

## 阶段 3：实现氧气系统

### 要做什么

1. 给玩家添加 `oxygen` 和 `maxOxygen`
2. 每帧或每秒扣除氧气
3. 绘制氧气条
4. 氧气不足时改变颜色

### 输出结果

- 游戏开始后氧气持续下降

### 怎么验证

- 站着不动也会掉氧气
- 掉到低值时 UI 颜色改变
- 氧气为 0 时触发危险状态

---

## 阶段 4：实现资源对象与采集

### 要做什么

1. 创建 `ResourceItem` 类
2. 在地图上放置资源
3. 接近资源显示提示
4. 按键采集并加入背包

### 输出结果

- 玩家可以拾取和采集资源

### 怎么验证

- 采集后资源从地图消失
- 背包数量增加
- 背包满时无法继续采集

---

## 阶段 5：实现返航与结算界面

### 要做什么

1. 设置海面安全区域
2. 玩家返回安全区域后结束本次出航
3. 统计资源并生成结算界面
4. 结算收入并增加金币

### 输出结果

- 游戏第一次形成完整循环

### 怎么验证

- 下潜采集后返回可成功结算
- 金币增加数值正确
- 第二次出航状态能正常重置

---

## 阶段 6：实现升级系统

### 要做什么

1. 创建基地界面
2. 创建 `UpgradeManager`
3. 实现升级按钮、金币扣除和效果应用
4. 升级后再次出航体验差异

### 输出结果

- 玩家可以把收益转化为成长

### 怎么验证

- 升级前后最大氧气或速度有明确变化
- 金币不足时无法升级
- 升级数据不会乱跳

---

## 阶段 7：增加危险生物和环境机制

### 要做什么

1. 加入至少一种巡逻生物
2. 加入至少一种危险地形
3. 碰撞后造成伤害或异常状态

### 输出结果

- 游戏出现风险与博弈

### 怎么验证

- 生物会移动
- 玩家接触后扣血或异常
- 危险效果结束后能恢复

---

## 阶段 8：做海域推进与第二张地图

### 要做什么

1. 增加第二海域
2. 设置解锁条件
3. 调整资源和敌人分布

### 输出结果

- 游戏有中期目标

### 怎么验证

- 未满足条件时不能进入
- 满足条件后可以解锁
- 第二海域明显比第一海域更难

---

## 阶段 9：补齐 UI、音效、图鉴、存档

### 要做什么

1. 完善菜单界面
2. 添加基础音效
3. 实现简单图鉴
4. 写入本地存档

### 输出结果

- 作品完成度显著提升

### 怎么验证

- 退出重进后金币与升级仍存在
- 已见过资源会记录在图鉴中
- UI 切换无明显 bug
