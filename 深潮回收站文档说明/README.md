# 深潮回收站文档说明

本文档目录用于支撑 `深潮回收站` 项目的持续开发、阶段测试、架构梳理和最终视频录制。

本目录的使用原则：

1. 先看 `项目工作流程.md`，明确项目应该按什么顺序推进。
2. 每进入一个开发阶段，配合 `执行计划与测试.md` 落地任务和测试。
3. 写代码前先遵守 `AGENTS.md`，统一技术栈、风格和命令。
4. 需要理解模块关系时，优先看 `架构概览.md`。
5. 准备录视频时，按顺序使用 `视频讲解提纲.md`、`视频逐段脚本.md`、`视频演示流程与检查清单.md`。
6. 讲解“难点与解决方案”时，参考 `开发难点与解决策略.md`。

## 文档列表

- `项目工作流程.md`
  项目的总推进路线图，回答“先做什么、后做什么、为什么这样做”。

- `执行计划与测试.md`
  按阶段列出任务、测试动作、通过标准和回归检查。

- `架构概览.md`
  梳理模块边界、关键类、主循环、数据流和资源组织方式。

- `AGENTS.md`
  记录稳定、长期有效的项目约定，包括技术栈、代码风格、已知陷阱、关键命令和必跑命令。

- `视频讲解提纲.md`
  把课程要求的视频内容拆成可讲的章节，适合先搭讲解结构。

- `视频逐段脚本.md`
  提供 5 到 8 分钟的逐段讲稿和画面切换建议。

- `视频演示流程与检查清单.md`
  录制前、中、后的检查表，避免漏讲、漏录、卡顿或现场翻车。

- `开发难点与解决策略.md`
  提前整理项目开发中的技术难点、风险点和对应解决方案。
